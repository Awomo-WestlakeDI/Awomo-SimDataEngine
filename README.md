# Awomo-SimDataEngine project page

Research project-page preview featuring SimForge text-to-scene generation, Unravel image-to-scene reconstruction, articulated-asset motion, and the shared graph-native harness.

The page includes eight Unravel input images, two interactive reconstructed scenes, and ten articulated-asset motion examples. Additional reconstruction examples, author information, and final publication links will be added later.

Serve this directory with a static HTTP server to preview. For GitHub Pages, publish the root of the `main` branch.
